# 🤖 Teo IA - Asistente Educativo con Inteligencia Artificial

> Proyecto desarrollado como parte del Programa COIL (Aprendizaje Colaborativo Internacional y en Línea) entre INACAP y la Universidad de Salamanca.

## 📝 Descripción
Teo IA es un asistente virtual diseñado para enseñar matemáticas a estudiantes de primaria y secundaria. La plataforma utiliza Inteligencia Artificial para ofrecer una experiencia de aprendizaje interactiva, adaptándose a las necesidades del estudiante mediante perfiles de tutor intercambiables y comprensión de contexto a través de documentos.

## 🚀 Características Principales
* **Integración de IA (RAG):** Capacidad de leer y procesar apuntes en formato PDF/Word para proporcionar respuestas contextualizadas basadas en el material de estudio.
* **Perfiles Intercambiables:** Diferentes estilos de tutoría adaptados a distintos niveles educativos.
* **Evaluación Interactiva:** Generación de quizzes con corrección automática.
* **Pizarra Gráfica:** Visualización de problemas matemáticos utilizando Matplotlib.

## 🛠️ Tecnologías Utilizadas
* **Backend:** Python
* **Frontend/Interfaz:** Streamlit
* **IA:** API de OpenAI (GPT-4o-mini)
